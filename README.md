# 🎵 AI 音樂創作家：我的車城專屬校歌

## 🗺️ 四關闖關

| 關卡 | 名稱 | 學生要做的事 | 通關條件 |
|---|---|---|---|
| 1 | 傳統校歌解密 | 觀看校歌影片、閱讀樂譜，把四句歌詞配對到家鄉風景 | 配對全對、測驗答對、討論紀錄 15 字以上 |
| 2 | 特色歌詞改編 | 為三校區各寫 2～4 句白話歌詞，一鍵組合成完整歌詞 | 每區 40 字以上、完整歌詞 150 字以上 |
| 3 | AI 曲風魔法師 | 選曲風、心情、演唱者、樂器，複製「Suno 貼上包」到 Suno 生成歌曲 | 取好歌名，上傳 MP3 或貼上分享連結 |
| 4 | 專屬校歌發表會 | 寫創作理念、歌詞彩蛋與心得，選擇是否放上成果展示 | 各欄位達到最低字數 |

## 🎹 Suno 操作步驟（學生版）

網站會先把三樣東西準備好，學生到 Suno 只需要「貼上」：

1. 按「開啟 Suno 建立頁」，上方切換到 **Advanced**，模型保持 **v6-mini**（免費）
2. **先用滑鼠點一下 Lyrics 框**，再按 Ctrl+V 貼上歌詞
3. 點一下 **Styles** 框，貼上英文曲風
4. 打開 **More Options**，依網站黃色提示設定 Vocal Gender，其他不要動
5. 點一下 **Song Title**，貼上歌名
6. 按 **Create**，約 30 秒會出現 4 首
7. **只選標示「V6-MINI」的 2 首**（「V6 PREVIEW」是付費試聽，不完整）
8. 按「⋯」→ **Download** 存成 MP3 上傳回網站，或按 **Share** 複製連結

> ⚠️ 不要按 **Publish**，那會把歌公開到 Suno 網站。每組只按一次 Create，以免用完點數。

## 👩‍🏫 教師功能

- **教師主控台**：網站右上角進入，提供表格、清單、圖卡三種檢視，可依日期篩選、聚焦單一欄位，並匯出 CSV
- **成果展示網站**：只顯示學生勾選「同意展示」的作品，姓名自動遮一字（例如 王○明）
- **發表會模式**：在成果展示頁按「🎬 發表會模式」投影，用 ← → 方向鍵切換作品
- **下架作品**：在試算表把該生的 `showcaseHidden` 欄改成 `TRUE`

## 🏗️ 系統架構

```
GitHub Pages（index.html / showcase.html）
        │  JSONP（讀取）＋ text/plain POST（寫入）
        ▼
Google Apps Script Web App（Code.gs）
        │
        ├─► Google 試算表（Students、Config 工作表）
        └─► Google 雲端硬碟（AI校歌成果作品 資料夾）
```

- 不呼叫任何 AI API，**免 API Key**，學生直接在 Suno 創作
- 學生以 **ptc 開頭的屏東縣帳號**登入，進度自動保存
- 作品檔採**分塊上傳**（每塊約 2MB），單檔最大 20MB
- 自建輕量 CSS，不使用 Tailwind CDN

## 🚀 部署方式

### 1. 後端（Google Apps Script）

1. 建立一份新的 Google 試算表 → 擴充功能 → Apps Script → 貼上 `Code.gs`
2. 執行 `setupDatabase`，按允許授權（會建立工作表和雲端硬碟資料夾）
3. 到 **Config** 工作表修改 `teacherPassword`
4. 部署 → 新增部署作業 → 網頁應用程式
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 複製 Web App 網址

### 2. 前端（GitHub Pages）

1. 把網址貼到 `index.html` 和 `showcase.html` 的 `DEFAULT_GAS_URL`
2. 上傳所有檔案到儲存庫
3. Settings → Pages → Branch 選 `main`，儲存

### ✅ 檢查是否連線成功

用無痕視窗開啟 `你的GAS網址?action=ping`，看到 `{"success":true,"version":"v1.1"}` 就代表後端正常。

> 💡 之後修改後端時，請用「管理部署作業 → 編輯 → 版本選『新版本』」，網址才不會變。
